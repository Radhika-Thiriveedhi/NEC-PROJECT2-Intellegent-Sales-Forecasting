# Intelligent Sales Forecasting & Inventory Optimization System

## Overview

An end-to-end Business Intelligence and Machine Learning application developed using Python and Streamlit. The system analyzes historical sales data, performs preprocessing, visualizes business trends, forecasts future sales demand, and provides inventory optimization recommendations.

## Features

* Sales Data Upload
* Data Preprocessing
* Exploratory Data Analysis (EDA)
* Random Forest Model Training
* Sales Forecasting
* Inventory Optimization
* Business Reports
* Interactive Dashboard

## Technologies Used

* Python
* Streamlit
* Pandas
* NumPy
* Plotly
* Scikit-learn
* Joblib

## Project Workflow

1. Upload Sales Dataset
2. Preprocess Data
3. Analyze Sales Trends
4. Train Machine Learning Model
5. Forecast Future Sales
6. Optimize Inventory Levels
7. Generate Reports and Dashboard

## Run the Project

```bash
pip install -r requirements.txt
streamlit run app.py
```
